# Главный экран и региональный атлас — 20 октября 2026

Исправлена причина узкой колонки: viewport-зависимый левый отступ находился
внутри контейнера с max-width 860px. Новый внешний контейнер управляет полями,
а две колонки используют minmax(0, ...). На телефоне они складываются вертикально.

Первый экран показывает всю область Абай. Геометрия строится из локального
контура OpenStreetMap, точки — из существующих записей историй. Толщина условная:
это стилизованный атлас, а не измеренный рельеф. Подробная карта с рельефом сохранена.

## Подтверждено на production preview

- `npm run build`: TypeScript и production build прошли; `npm test`: 14/14.
- `node tools/verify-home.mjs`: 11 проверок размещения. RU/KK/EN на
  390×844, 1440×960 и 2560×1349; дополнительно крупный казахский текст,
  высокий контраст, уменьшение движения и подписи после поворота.
- Мышь, кнопки, клавиатура, приближение, возврат камеры, пять направлений,
  географический маркер, открытие истории и переход в подробную карту работают.
- Подписи близких мест не перекрываются. Камера помещает контур в кадр.
- При отсутствии WebGL отображается реальная SVG-граница; история открывается.
- При ошибке загрузки геоданных видны сообщение и список направлений.
- После отключения сети уже загруженная сцена остаётся видимой. Работа после
  перезагрузки без сети не заявляется: service worker в рамках этой задачи не добавлялся.
- Данные сцены локальные; внешние тайлы для главного экрана не требуются.
- Скриншоты и JSON: `.research/home-redesign/`. Для браузерных проверок использован
  headless Chrome с SwiftShader; это не измерение производительности реального телефона.
- Механический детектор Impeccable вернул пустой список замечаний.

Обработчики и файлы гида, его модель и onboarding принадлежат соседнему чату.
В App.tsx здесь заменён только главный hero и добавлен импорт HomeJourney.
Контрольные data-start-tour и маршруты сохранены. Параллельные изменения гида
