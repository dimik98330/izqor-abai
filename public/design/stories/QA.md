# Проверка макета страниц историй

Проверен отдельный макет `/design/stories/index.html?place=konyr` в Chrome. Основное приложение в `src/` не изменялось.

- Пять мест × три языка при 390 px: заголовки и текст переключаются; горизонтального переполнения нет. Матрица измерений: `.research/stories-mockup/mobile-checks.json`.
- Дополнительно проверено самое длинное название при 320 и 768 px: переполнения нет. Обложка и чтение просмотрены при 1440 px.
- Раскрытие источника работает; отображается название материала и внешняя ссылка. Крупный текст на десктопе меняется с 18 до 21 px, на телефоне с 16 до 19 px.
- Фотография открывается в диалоге; закрытие и возврат к странице проверены. Панель гида открывается с материалом выбранного места и закрывается.
- Закладка меняет состояние и сохраняется при переключении мест в пределах макета. Плеер раскрывается и меняет состояние запуска/паузы, явно обозначен как демонстрация без звука.
- По последней правке пользователя из всех пяти историй удалены отдельные нижние блоки посещения и библиографии. В оглавлении убран пункт библиографии; действие источников в панели гида открывает источник у абзаца.
- Ошибок в журнале браузера во время финального просмотра не обнаружено. `node --check` проходит. Все идентификаторы источников в библиографиях разрешаются.
- Копирование реализовано через Clipboard API с запасным полем ссылки. Содержимое системного буфера не считывалось; отдельное подтверждение скопированного значения не получено.

Механический скан нашёл отсутствующий `src` у изначально закрытого фотодиалога; добавлена исходная фотография по умолчанию. Предупреждение о светлой тёплой палитре — сознательное сохранение идентичности IZQOR. Предупреждение об отступах внешней полосы макета проверено визуально: внутренний контейнер центрирует содержимое с запасом по высоте.

Скриншоты сохранены в `.research/stories-mockup/`: `desktop-cover.png`, `desktop-reading.png`, `mobile-390-en.png`.

Ограничения: это визуальный интерактивный прототип. Реальные озвучка и генеративный гид не подключены; их нужно использовать из действующего приложения при внедрении. Проверка телефона выполнена эмуляцией ширины в Chrome.
