# Google Sans — IZQOR home interface

Unmodified Google Sans variable WOFF2 language subsets, weight range 400–700.
Downloaded from the official Google Fonts CSS API on 2026-10-20 (provider version v71).

- Source project: https://github.com/googlefonts/googlesans
- License: SIL Open Font License 1.1, included in `OFL.txt`.
- Subsets: Latin, Latin Extended, Cyrillic, Cyrillic Extended.
- Total stored font data: 89,456 bytes. Browsers request only the subsets needed by displayed text.
- Original provider URLs and byte counts: `.research/keylight-controls/font-manifest.json` in the project.

The font files are served locally. Typography is applied only to the home route through `src/home-controls.css` and `src/home-fonts.css`.
