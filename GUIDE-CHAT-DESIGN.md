# Жолсерік: окно переписки — 20 октября 2026

## Вторая итерация: визуальная система (20 октября 2026)

Запрос пользователя: «красиво сделай все кнопки, иконки, стиль, текст». Переработана
вся визуальная оболочка окна переписки — логика, API и контракты не тронуты.

| Проблема | Изменение |
|---|---|
| Панель была на Inter и жила отдельно от сайта | Noto Serif (имя, приветствие) и Golos Text (интерфейс, ответы) — как в DESIGN.md; `@import` Inter из модуля убран |
| Самодельная чёрно-белая палитра | Токены сайта в тёмном варианте: midnight `#082b30`, пергамент `#f7f3e9`, латунь `#c9a66b` |
| Золото в бренде не использовалось | Латунь: иконки подсказок, пин места, «+», шеврон, цитаты, кнопка отправки, фокус |
| Три подсказки: одна белая залитая, две с жирной рамкой, hover `scale(1.05)` | Три одинаковые карточки 14 px, латунные иконки, hover без сдвига геометрии (стрелка уезжает на 2 px) |
| Тяжёлая рамка у «Новый разговор» и у кнопки закрытия | Спокойные кнопки-чипы 44 × 44 с мягкой рамкой и подсветкой при наведении |
| Пустая строка места с провалом и висящей отдельно кнопкой паузы | «Место» с иконкой, чип с выбором по ширине содержимого, кнопка фона прижата вправо |
| Серая кнопка отправки выглядела как системный контрол | Активная кнопка — латунь с тёмным текстом, выключенная — приглушённая |
| Много одновременных анимаций появления | Одна «авторская» сцена: панель и её затемнение появляются вместе (320/420 мс) |
| Композиция приветствия разваливалась | Блок по центру, описание ограничено 44 знаками, три карточки единой сеткой |
| Видеофон стал нечитаемым | Затемнение ослаблено, пейзаж снова виден, текст прикрыт тенью |
| При выборе места и при вводе текста вокруг поля появлялась двойная обводка (глобальное правило `select:focus-visible, textarea:focus-visible` — 3 px латуни с отступом 4 px поверх рамки компонента) | Рамки убраны: чип места при фокусе только слегка теплеет, у поля ввода остаётся тонкая латунная граница; фокус-кольцо у кнопок сохранено |

Проверено в браузере: `tools/verify-guide-ui.mjs` — 15 раскладок, контраст
закрытия и «Новый разговор» 13.5 : 1, фокус 6.5 : 1, пауза/воспроизведение
видео, остановка ответа с возвратом черновика, повтор после ошибки, клавиатурная
отправка, читаемость источников, смена места, работа при падении видео.
Снимки «до/после»: `.research/guide-redesign/`.

## Первая итерация

Область работы подтверждена пользователем: только окно переписки, без сообщений
в соседний чат и без изменений 3D-персонажа или пошагового знакомства.

## Диагностика и результат

| Проблема | Изменение |
|---|---|
| Повторяющиеся заголовки и технический статус | Одна шапка: персонаж, имя, короткая подпись и понятные действия |
| Большой портрет отодвигал сообщения вниз | Компактное представление существующего персонажа |
| Набор одинаковых карточек | Три спокойные строки с вопросами и иконками Lucide |
| Вопрос исчезал на время запроса | Вопрос сразу появляется в ленте; ожидание можно остановить |
| Мелкие ссылки и повторяющиеся подписи | Кликабельные сноски и раскрываемые источники с настоящим количеством |
| Нет удобного восстановления после ошибки | Короткое сообщение и повтор вопроса без дублирования истории |
| Незаметный фокус полей | Видимый бронзовый контур ввода, выбора места и кнопок |
| Общие стили менялись параллельно | Изолированный CSS namespace izqor-conversation |

Тексты подготовлены для русского, казахского и английского. Сохранены существующие
контракты API, память разговора, выбор места и отмена запросов. Поле ввода остаётся
доступно при длинной переписке. Остановка возвращает вопрос в поле.

## Референсы и навыки

- [Bloomberg Connects](https://www.bloombergconnects.org/) — личный культурный проводник,
  короткое знакомство и самостоятельное исследование.
- [ArtLens](https://www.clevelandart.org/digital-innovations/artlens-app) — ясная связь
  выбранного места с его историей.
- [Carbon Chatbot](https://carbondesignsystem.com/community/patterns/chatbot/usage/)
  — постоянные шапка и ввод, различимые реплики, стартовые вопросы.
- [Design Museum: Press Feedback](https://publieople.github.io/design-museum/entry/press-feedback/)
  и [Text Balance](https://publieople.github.io/design-museum/entry/text-balance/)
  — короткая обратная связь кнопок, сбалансированное приветствие, режим без движения.

Zack redesign/anti-ai использованы для аудита и приоритизации. Два субагента
независимо исследовали референсы и проверили удобство. SeeCode и diagram-design
прочитаны как инструменты схем; схемы в пользовательское окно не добавлялись.

## Проверка

- TypeScript и production build проходят; `npm test`: 26/26.
- `node tools/verify-guide-ui.mjs`: 14 проверок размещения, все прошли.
- Размеры: 1440×960, 1024×768, 390×844. Проверены три языка, длинные сообщения,

  черновика, повтор ошибки, память после закрытия, новый разговор и смена места.

  Контраст фокуса к фону 4.80:1. Горизонтального переполнения нет.
- Нет ошибок JavaScript. Визуальные проверки использовали подготовленные ответы:
  платных обращений к модели в этой работе не было.

Снимки, исходное состояние и JSON-отчёт находятся в `.research/guide-redesign/`.
