# Жолсерік: cinematic-вариант — 20 октября 2026

По новому референсу пользователя обновлено только окно переписки. Сохранены
его структура, выбор места, тексты на RU/KK/EN, существующий 3D-персонаж и API.

Добавлены Inter, белые контурные действия, основная белая кнопка с чёрным текстом,
плавное последовательное появление и пейзаж степи, созданный через встроенный
imagegen. По последнему замечанию пользователя прежнее видео с самолётом
заменено в HTML и основном окне гида. Ковыль, полынь, невысокие холмы,
соломенно-золотой свет и шалфейные оттенки согласованы с тёмно-зелёной
палитрой IZQOR. Это декоративная сцена по мотивам региона, не документальная
съёмка конкретного места. Текст об этом в интерфейс не добавлялся.

Параметры обычного режима: заголовок 56px / 38px, вес 500, line-height 1.1;
подзаголовок 18px / 15px; действие в шапке 14px regular; основная кнопка
15px medium, отступы 26px по горизонтали и 12px по вертикали. Крупный текст
и режим высокого контраста остаются доступны.

Видео покрывает область, автоматически воспроизводится без звука, зациклено,
поддерживает playsinline. Это локальный 32-секундный цикл 1920×1080 / 24 fps
с медленным движением камеры, созданный из пейзажа через FFmpeg. Замкнутая
синусоидальная траектория возвращается к исходному кадру. Тёмно-зелёное
затемнение и поверхности переписки сохраняют читаемость. Можно остановить фон.
При reduced-motion и скрытой странице воспроизведение приостанавливается;
при ошибке загрузки остаются неподвижный пейзаж и работающий чат.

Оформление изолировано в `src/guide-chat.module.css`; GuidePanel импортирует
CSS-модуль. Старый `guide-chat.css` больше не является его рабочим стилем.
Настройки других экранов, пошаговое знакомство и модель не редактировались.

## Однофайловая версия

`public/guide-cinematic.html` — один HTML с Tailwind Play CDN, Google Inter,
встроенным портретом существующего персонажа, локальным видео, тремя языками,
мобильным меню и чатом. Логотип IZQOR текстовый; навигация ведёт в реальные
разделы проекта. Серверный API используется через `/api/guide`, ключ в HTML
отсутствует. Поэтому работа ИИ требует запуска сервера проекта.

Открытие: http://127.0.0.1:4173/guide-cinematic.html . Основной сайт:
http://127.0.0.1:4173/ . Для переноса HTML нужны также два файла из `public/media`:
`abai-steppe-loop.mp4` (7.23 MB) и `abai-steppe-poster.webp` (326 KB).
Удалённое видео SceneAI больше не используется. Портрет экспортирован из
существующей локальной 3D-сцены.

- Рабочее окно: 15 состояний и размещений, три языка, 1440×960,
