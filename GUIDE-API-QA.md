# ИИ-гид — 20 октября 2026

Подключён OpenAI Responses API, модель gpt-5.4-mini. Ключ хранится только в
игнорируемом серверном env-файле; значение не записывается в исходники,
клиентскую сборку, ответы API или отчёты. Проверено совпадение серверной
конфигурации с предоставленным ключом без вывода самого значения.

## Что проверено

- TypeScript и production build проходят. `npm test`: **26/26**.
- Через собранный сайт на http://127.0.0.1:4173 выполнены восемь настоящих
  запросов в UI: русский, казахский, английский, уточнение о годе покупки дома,
  общий вопрос о цвете неба и проверка виртуальных экскурсий на сайте музея.
- Уточнение «в каком году он приобрёл этот дом?» получило **1898** с учётом
  предыдущей реплики. После закрытия и повторного открытия диалога реплики сохранились.
- В финальной проверке казахский ответ о Жидебае и английский об Алаше получили
  соответствующие проектные источники. Интернет-поиск вернул ссылки на музей;
  кликабельные сноски реально отрисовались внутри ответа.
- Общий ответ помечается как объяснение ИИ; ему не приписывается случайный источник.
- Кнопка нового разговора очищает историю. Закрытие во время задержанного ответа
  отменяет запрос; после переключения языка старый ответ не появляется.
- На 390×844 и 1440×960 поле ввода находится внутри диалога. История прокручивается,
  элементы управления остаются доступны. Это проверка браузера, не реального телефона.
- Смоделирован исчерпанный баланс: показано отдельное понятное сообщение,
  доступны справочный ответ и его ссылки. Разделение auth/quota/rate/timeout,
  лимиты, роли сообщений и отказ от клиентского контекста проверены тестами.
- Запросы браузера не содержат Authorization и ключа. Доступ к серверному env-файлу
  через оба локальных сервера не возвращает ключ. Финальная сборка проверена повторно.

Артефакты: `.research/guide-api/browser-report.json`, `followup-report.json`,
`security-report.json`, `guide-desktop-final.png`, `guide-mobile-final.png`.
`tools/verify-guide.mjs` делает шесть платных запросов при явном запуске;
обычный `npm test` использует подменённый провайдер и ничего не оплачивает.

## Изменения и границы

Обработчик API работает на тех же адресах в dev и preview. Источники берутся
из серверного корпуса всех пяти мест и линии времени. Контекст выбранной точки
не ограничивает тему вопроса. Четыре последние пары реплик передаются модели;
шесть пар доступны в памяти страницы. Перезагрузка очищает диалоги.

Ограничения: 24 запроса в минуту с одного IP, три одновременных запроса,
1800 выходных токенов, один поисковый вызов, без автоматических платных повторов.
Поиск ограничен музейными, архивными, туристическими и официальными доменами.
Качество фактов и перевода не объявляется безошибочным: важные сведения остаются
проверяемыми по источникам. Публичное размещение и облачная озвучка не выполнялись.

Код персонажа не изменялся. Панель переписки вынесена из App.tsx в GuidePanel.tsx,
чтобы дальнейшая работа над внешностью и анимациями не пересекалась с логикой API.
Настройка, контракт и смена ключа описаны в AGENT_INTEGRATION.md.
