## О проекте

IZQOR помогает узнать регион через конкретные места: увидеть их на карте, прочитать историю, открыть музейную панораму и задать вопрос проводнику Жолсерік. У исторических материалов есть ссылки на источники; легенды, иллюстрации и архитектурные схемы обозначены отдельно.

Интерфейс, истории мест и исторические главы доступны на **казахском, русском и английском** языках. Сохранённые места, прогресс чтения и настройки остаются в браузере.

## Быстрый старт

Нужны **Node.js 22.12+ в ветке 22.x** и npm. Версия для менеджера Node указана в `.nvmrc`. Геоданные, шрифты и основные медиа уже входят в проект.

```bash
npm ci
npm run dev
```

Откройте [localhost:5173](http://127.0.0.1:5173). Сайт запускается без API-ключей: истории и локальная 3D-сцена доступны, карта предлагает список мест, а гид использует явно обозначенный справочный режим.

Для карты 2GIS и ответов AI-гида добавьте настройки ниже. Для чтения материалов аккаунт не требуется.

## Настройки

Скопируйте шаблоны в локальные файлы.

**PowerShell:**

```powershell
Copy-Item .env.example .env.local
Copy-Item .env.server.example .env.server.local
```

**macOS / Linux:**

```bash
cp .env.example .env.local
cp .env.server.example .env.server.local
```

| Переменная | Файл | Назначение |
| --- | --- | --- |
| `VITE_2GIS_API_KEY` | `.env.local` | Браузерный ключ 2GIS с доступом к Map Tiles / MapGL. |
| `VITE_GUIDE_ENDPOINT` | `.env.local` | Адрес API гида; по умолчанию `/api/guide`. Пустое значение включает справочный режим без обращения к API. |
| `OPENAI_API_KEY` | `.env.server.local` | Серверный ключ для ответов AI-гида. Без ключа доступен справочный режим. |
| `OPENAI_MODEL` | `.env.server.local` | Модель; значение по умолчанию — в шаблоне серверных настроек. |
| `GUIDE_WEB_SEARCH` | `.env.server.local` | `false` отключает веб-поиск гида; по умолчанию включён. |

После изменения `.env` перезапустите сервер; изменения `VITE_*` требуют новой сборки для готового сайта. Серверные ключи нельзя называть с префиксом `VITE_`: такие переменные попадают в клиент. Локальные настройки исключены из Git.

Настройка карты: [2GIS MapGL](docs/2gis-map.md). Контракт, ограничения запросов и поведение гида: [Guide integration](AGENT_INTEGRATION.md). Запросы к настроенному AI-провайдеру могут быть платными.

## Команды

| Команда | Действие |
| --- | --- |
| `npm run dev` | Локальная разработка: сайт и API на `127.0.0.1:5173`. |

## Сборка и размещение

```bash
npm run build
npm start
```

`npm start` предназначен для локального просмотра. Клиент использует hash-маршруты (`#/map`, `#/timeline`), поэтому для переходов между страницами не нужны серверные rewrite-правила.

На статическом хостинге, включая GitHub Pages, можно разместить содержимое `dist/`. При публикации в подпапку задайте Vite `base` перед сборкой, например `npm run build -- --base=/izqor/`. **Статический хостинг не запускает API гида:** для AI-ответов нужен отдельный Node.js-сервис, доступный через тот же origin, либо справочный режим (`VITE_GUIDE_ENDPOINT=`). Браузерный ключ карты задаётся до сборки.

Внешние карты, панорамы и AI требуют сети. Полноценный запуск без интернета не заявлен. Публичный деплой в этом репозитории пока не подтверждён.
