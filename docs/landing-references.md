# Landing references — 20 October 2026

The primary direction is the user-supplied Halden brief: a landscape occupying the whole first screen, quiet floating navigation and restrained motion. It is adapted to IZQOR's brand, three languages and real regional stories; its standalone HTML instructions are not applied to this React project.

## Concrete references

| Reference | Inspection | Applied | Not applied |
| --- | --- | --- | --- |
| [Getty — Persia](https://www.getty.edu/art/exhibitions/persia/) | Live page, desktop screenshot | An expansive subject image, clearly attributed cultural content, separation of atmosphere and editorial information | Exhibition calendar, commerce, old navigation styling |
| [Typewolf — Manrope](https://www.typewolf.com/manrope) | Live specimen, desktop screenshot | Evaluating readable modern sans typography beside a literary display face | Manrope itself: actual font files lack required Kazakh characters |
| [TypeTogether — Literata](https://www.typetogether.com/fonts/literata) | Official specimen and family information | Literata's literary character and screen-oriented display sizes | Commercial store UI and ornamental typography |
| [shadcn — Button](https://ui.shadcn.com/docs/components/button) | Live component page, desktop screenshot | A consistent control height, readable icon spacing, a distinct primary action | New framework dependencies or the generic neutral colour kit |
| [Lucide — Compass](https://lucide.dev/icons/compass) | Live icon specimen and related icon set, desktop screenshot | The existing consistent SVG family for play, zoom, fit-to-view and directional actions | Repeating location icons/checkmarks in each place tab |
| [Awwwards — Persepolis Reimagined](https://www.awwwards.com/sites/persepolis-reimagined) | Gallery and public project description read; live experience reached its loader only | Context for an immersive cultural experience | No claim that its complete live interaction was inspected or copied |

Main supporting references: Getty for cultural presentation; TypeTogether for typography. Component references inform details, not page composition. Only existing Lucide code and OFL fonts are used; no reference site's code or imagery is copied.

Screenshots, response statuses and page titles are stored in `.research/landing-2026-10/`. The files named `before` are the previous local implementation. `persepolis.png` is a loader, not a finished reference view.
